# Deviations from stock NetHack 3.6.6

PufferHack aims to play exactly the game of untouched stock NLE 0.9.0 (NetHack 3.6.6) built with gcc, plus NetHack 3.7's
`attknum = 0` fix in `hitum_cleave`. This file lists every known difference, from a line-by-line audit of the fork's
34K changed lines against stock, an execution diff of all setup state, about 6,000 wizard-mode games reaching every special
level, quest and endgame, and a coverage map of which changed lines the certified corpora execute (87.8%). `verify/` checks
a build against stock; its corpora pass with the expected outcomes in `verify/known.tsv` and `verify/stock/aborts.tsv`.

Severity: **major** = the game played can differ (random draws, state, key consumption) or the engine crashes where stock plays;
**minor** = only observations, messages, files or resources differ; **info** = no observable difference.
Reach: **K** = normal play under PufferLib's options; **OPT** = other options stock accepts; **API** = C API uses beyond
playing (seeding, checkpoints, changing buffer bindings, several data dirs); **UB** = stock crashes or reads undefined memory there.

## Kept on purpose

Differences PufferHack keeps by design (seeded clocks, the env-answered position prompt, guards where stock crashes or reads
undefined memory, observation extensions).
